Dongi  

A simple group‑expense management web application built with **ASP.NET Core MVC**, **Entity Framework Core**, **SQL Server**, and **ASP.NET Core Identity**.  
Users can create events, add members, record expenses, and see each person’s net balance.

Technologies  
- ASP.NET Core MVC (.NET 10 LTS)  
- Entity Framework Core  
- SQL Server  
- ASP.NET Core Identity (Individual Accounts)  
- Scaffolding MVC  
- Git & GitHub  

Features  
- User authentication with Identity (register/login)  
- Create and manage events  
- Add members (registered users only)  
- Add expenses with payer + participants  
- Auto‑split expenses equally  
- Calculate each member’s net balance  

Status  
MVP version – simple equal‑split logic, no advanced settlement suggestions yet.
